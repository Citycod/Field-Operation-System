# Archived Directus Prototype Notes

> [!NOTE]
> This folder contains historical reference documentation from the early Directus-based backend prototype phase.
> The active platform architecture was migrated to **Supabase** (PostgreSQL + Auth + Storage + RLS) before Form Builder Phase 1 implementation.

## Historical Architecture Summary (Deprecated)

- Backend Engine: Directus 11.x
- User Identity: `directus_users`
- Storage driver: Directus S3 plugin

Active development must refer to `docs/architecture/PLATFORM-ARCHITECTURE.md` and `supabase/migrations/`.
